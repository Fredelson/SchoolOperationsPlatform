============================================================
Date: 2026-07-20
Issue: Platform Foundation section rendering too many items

============================================================
ROOT CAUSE
============================================================

The sidebar is displaying orphaned root menus that have:
  1. ParentMenuId = NULL (no parent)
  2. No entry in dbo.MenuGroupItems (not assigned to any sidebar group)

Because these menus belong to ModuleId = 1 (platform_foundation),
the navigation service buckets them ALL into the
"Platform Foundation" sidebar section.

THE FIX
============================================================

Option A: Delete orphaned menus that duplicate *_ROOT containers
  - Menus like PRINTING, HR, COMMUNICATION, IT_OPERATIONS, etc.
    are duplicates of the *_ROOT container menus
  - Keep only the *_ROOT versions (PRINTING_MANAGEMENT_ROOT, etc.)

Option B: Link orphaned menus to their correct MenuGroups
  - Link IT_ASSETS_* menus to OPERATIONS group (12)
  - Link *_ROOT containers to their respective module groups
  - Link role dashboards to appropriate groups

Option C: Disable orphaned menus
  - Set VisibilityStatusId = 2 (Hidden) for all orphaned menus
  - They will still appear as "Soon" but not clutter active nav

Option D: Clean up ModuleId assignments
  - Move menus to their correct ModuleId
  - E.g., IT_ASSETS_* should be ModuleId = 6, not 1

============================================================
RECOMMENDED ACTION
============================================================

1. Run diagnostic query to confirm orphaned menus:
   SELECT m.MenuId, m.MenuKey, m.ModuleId, m.ParentMenuId,
          mgi.MenuGroupItemId AS 'HasGroup'
   FROM dbo.Menus m
   LEFT JOIN dbo.MenuGroupItems mgi ON m.MenuId = mgi.MenuId
   WHERE m.ParentMenuId IS NULL
     AND m.MenuKey NOT IN ('DASHBOARD')
   ORDER BY m.ModuleId, m.SortOrder

2. Decide which orphaned menus to keep/delete/reassign

3. Either:
   - Delete duplicates (keep only *_ROOT containers)
   - OR assign them to correct MenuGroups via INSERT INTO MenuGroupItems
