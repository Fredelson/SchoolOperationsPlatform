HOW ROUTE PROTECTION WORKS AFTER CHANGE
==============================================================

CURRENT:
  Route: GET /api/printing/queue
  Middleware: requirePermission("printing.queue.view")
  → checks user's resolved permission keys
  → returns 403 if missing

NEW:
  Route: GET /api/printing/queue  
  Middleware: requireWorkspaceAccess("printing", "queue")
  → checks if user has active assignment to a workspace
  → checks if that workspace has Printing module IsVisible=1, IsEnabled=1
  → checks if user's role in that workspace allows it
  → checks for individual overrides
  → returns 403 if not allowed

ALTERNATIVELY, even simpler:
  Route: GET /api/printing/queue
  Middleware: requireActiveWorkspace()
  → user must have active workspace assignment
  → workspace must have the feature enabled
  → no per-route permission key check needed
  → feature visibility controlled by WorkspaceModules.IsEnabled

INNER JOIN dbo.Permissions p ON rp.PermissionId = p.PermissionId

  AND p.ModuleId NOT IN (1)  -- only keep workspace module if needed
  AND p.IsActive = 0;

-- 4. Grant only 3 workspace permissions to all workspace roles
INSERT INTO dbo.RolePermissions (RoleId, PermissionId, IsAllowed, CreatedAt)
SELECT r.RoleId, p.PermissionId, 1, GETDATE()
FROM dbo.Roles r
CROSS JOIN (
  SELECT PermissionId FROM dbo.Permissions
  WHERE PermissionKey IN ('workspace.view', 'workspace.activate', 'workspace.disable')
) p
WHERE r.RoleKey NOT IN ('SuperAdmin', 'PlatformAdmin')
  AND NOT EXISTS (
    SELECT 1 FROM dbo.RolePermissions rp 
    WHERE rp.RoleId = r.RoleId AND rp.PermissionId = p.PermissionId
  );

NEW MIDDLEWARE: requireWorkspaceAccess
==============================================================

Replace requirePermission with this for all non-admin routes:

async function requireWorkspaceAccess(req, res, next) {
  const userId = req.user.id;
  
  // 1. Get user's active workspace assignment
  const workspace = await getUserActiveWorkspace(userId);
  if (!workspace) {
    return res.status(403).json({
      success: false,
      message: "No active workspace assigned."
    });
  }

  // 2. Check if the feature/module is enabled in this workspace
  const moduleKey = req.params.module || req.body.moduleKey;
  const isModuleEnabled = await isWorkspaceModuleEnabled(workspace.WorkspaceId, moduleKey);
  
  if (!isModuleEnabled) {
    return res.status(403).json({
      success: false,
      message: "Feature not available in your workspace."
    });
  }

  // 3. Apply individual overrides
  const override = await getUserPermissionOverride(userId, moduleKey);
  if (override && !override.IsAllowed) {
    return res.status(403).json({
      success: false,
      message: "Access denied by administrator."
    });
  }

  req.workspace = workspace;
  next();
}
