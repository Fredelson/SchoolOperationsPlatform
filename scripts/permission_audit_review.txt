SCHEMA ISSUE IDENTIFIED
==============================================================

The live database was created/altered using scripts/july20.sql
which defines dbo.Permissions WITHOUT GroupKey/GroupName columns
(only PermissionGroupId). However, the backend code selects
p.GroupKey and p.GroupName in many queries.

FIX: Run this SQL to add the missing columns:

  ALTER TABLE dbo.Permissions ADD 
    GroupKey nvarchar(100) NOT NULL DEFAULT 'platform',
    GroupName nvarchar(150) NOT NULL DEFAULT 'Platform';

This will resolve the  Invalid column name GroupKey  error
occurring during permission resolution (login/logout).
